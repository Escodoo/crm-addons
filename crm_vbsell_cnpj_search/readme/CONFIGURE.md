Install Brazilian Localization CNPJ Search and choose the provider (ReceitaWS or
SERPRO) in the Brazilian localization settings. ReceitaWS allows three lookups
per minute. SERPRO is a paid service.

Then, in the VBSell block of CRM settings, enable Look Up CNPJ for each
company that should query the registry. Companies that leave it off keep the
name sent by VBSell.
