Synchronize Odoo CRM opportunities with VBSell.

Inbound stage changes arrive on a signed webhook. Outbound stage, won
and lost changes are sent back to the VBSell API by a retried job.
Writes that came from VBSell are not pushed again.

Configuration
=============

Open CRM settings and, for each company:

- Enable the sync and set the API base URL, API key and webhook secret.
- Set the VBSell company UUID so inbound events find this company.
- Choose the default salesperson, source and lost reason.
- Choose the minimum VBSell stage that may create a lead. Earlier stages
  update an existing lead and do not create one.

On each CRM stage, set VBSell Stage. Use at most one stage per value on
a sales team. Stages left empty are not pushed to VBSell. The Won value
can only be set on a stage that is marked as won. Lost is not a stage.

Outbound updates use the ``root.vbsell`` job channel. Give that channel
a capacity in the queue job configuration, for example
``channels = root:2,root.vbsell:1``. A failed call is retried. The lead
chatter receives the error when the last retry fails.

Usage
=====

Point the VBSell webhook to
``https://<odoo>/vbsell/webhook/opportunity`` and subscribe it to
``opportunity.stage_changed`` only. The same secret configured in Odoo
must sign the request.

A VBSell stage at or above the configured minimum creates the partner
and the opportunity. When the contact tax id is a CNPJ, Odoo creates the
company and a contact linked to that company. The opportunity customer
is the contact. A CPF or any other tax id stays a single partner. Later
stage changes, including won and lost, update that opportunity. Changing
the stage in Odoo enqueues one job per lead. When the job runs, it sends
the stage that is current at that moment, including won and lost. A
stage without a VBSell value is not sent.
